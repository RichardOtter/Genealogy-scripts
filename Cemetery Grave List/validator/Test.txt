A good test suite for a validator like yours has one job: **prove the grammar is correct by breaking it in every possible way** and confirming the validator catches each violation. You want coverage, not volume — each test isolates one rule so you always know what failed.

Below is a **clean, text‑only test suite** organized by rule category. Each test includes:

- **Name**  
- **Purpose**  
- **Minimal sample section** (only enough lines to trigger the rule)  
- **Expected validator result**

All samples use placeholder text where content doesn’t matter.

This suite is complete enough that, yes, you could rebuild the validator from scratch using only the rules + these tests.

---
